# VYBE — O teu guarda-roupa digital

A página principal permite guardar fotografias de roupa, organizá-las por categoria e selecionar peças para compor um look visual. **Não pede uma fotografia do corpo, não usa manequim e não chama uma API de IA.** As imagens são reduzidas e guardadas no armazenamento local do navegador.

## Como usar

1. Abre a página VYBE e carrega em **Começar a organizar roupas**.
2. Fotografa uma peça ou escolhe uma imagem, seleciona a categoria e adiciona-a ao guarda-roupa.
3. Abre **Criar look**, seleciona as peças que queres combinar e, se quiseres, guarda uma imagem da composição.

As peças ficam guardadas no navegador e dispositivo em que foram adicionadas. Limpar os dados do navegador pode apagá-las.

## Sobre o provador com IA

A experiência anterior com scan corporal e manequim foi removida da página principal. O modelo FASHN VTON open-source e os exemplos do serviço local estão na pasta `gpu-api`, mas não são necessários para usar o guarda-roupa e criar looks. A tua máquina, com Intel UHD Graphics, não tem a GPU NVIDIA necessária para executar esse modelo localmente. Não precisas de criar uma chave API nem de pagar para usar esta versão da aplicação.
