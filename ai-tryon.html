Esta versão usa o modelo FASHN VTON de código aberto num servidor que tu controlas. As fotografias são enviadas para esse servidor e não para a API paga da FASHN.

Configuração do servidor local

Se o servidor estiver noutro endereço, indica-o aqui (por exemplo, http://127.0.0.1:8000). Este valor fica guardado apenas neste navegador.

O modelo e os pesos são gratuitos sob a licença Apache 2.0, mas precisas de uma máquina com GPU NVIDIA/CUDA compatível. O processamento corre nessa máquina; um servidor GPU na nuvem pode ter custos. Não exponhas o servidor à Internet sem autenticação e limites de utilização.
